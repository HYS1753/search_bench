# 화면 디자인 · 모션 원칙

SearchBench 는 Linear · Vercel · Raycast · Stripe 대시보드처럼 **조용하고 빠른** 도구를 지향합니다. 장식보다 내용이 먼저 보이고, 움직임은 상태 변화를 설명할 때만 씁니다.

## 브랜드

| 요소 | 내용 |
|---|---|
| 이름 | **SearchBench** — 검색 품질 판정 랩. 화면에서 `Search` 는 본문색, `Bench` 는 강조색 |
| 로고 | 둥근 사각형 안의 오름차순 막대 3개(순위·벤치마크). 가장 높은 막대 = 더 나은 결과. `components/brand/Logo.tsx`, `public/favicon.svg` |
| 색 | 중립 회색 바탕 + 인디고 강조(`--accent`). 좋음/나쁨/주의는 초록/빨강/주황. 라이트·다크 모두 CSS 변수(`index.css`) |
| 글꼴 | Pretendard Variable, 숫자는 고정폭(tabular) |

## 레이아웃

- **상자 대신 선**: 영역은 얇은 가로선·세로선으로 나눕니다(`Rows`, `FormRow`, `StatRow`). 카드는 강조가 필요한 곳(시작하기 카드, 선택지)에만.
- 왼쪽 사이드바(그룹: 평가 / 연결 / 평가 구성 / 시스템 / 도움말)와 본문은 세로선으로 구분. 선택된 메뉴는 강조색 막대와 아이콘 색으로 표시.
- 모든 행·칸은 폭이 줄면 줄바꿈되고 페이지 가로 넘침이 없게 합니다(375 · 768 · 1024 · 1280px 확인).

## 모션 (`index.css` 의 모션 시스템)

| 원칙 | 값 |
|---|---|
| 길이 | 120–280ms(진입), 120–180ms(퇴장 — 진입보다 짧게) |
| 거리 | 4–8px 위로, 패널은 28px 옆으로 |
| 곡선 | `--ease-out` cubic-bezier(0.22, 1, 0.36, 1), 튀는 강조는 `--ease-spring` |
| 접근성 | `prefers-reduced-motion: reduce` 이면 모든 애니메이션·전환을 끕니다 |

| 쓰임 | 클래스 · 컴포넌트 |
|---|---|
| 화면 전환 | 경로가 바뀌면 본문이 살짝 떠오르며 나타남(`animate-page`), 맨 위로 스크롤 |
| 목록 순차 등장 | `stagger` — 자식마다 40ms 씩 늦게 |
| 대화상자 · 패널 · 툴팁 | Radix `data-state` 로 열림/닫힘 애니메이션(`dialog-anim`, `drawer-anim`, `overlay-anim`, `tooltip-anim`) |
| 알림 | 아래에서 올라오고 남은 시간 막대가 줄어듦, 마우스를 올리면 멈춤, 닫기 버튼 |
| 로딩 | 스피너 대신 모양을 미리 보여 주는 스켈레톤(`PageSkeleton`, `Skeleton`) |
| 숫자 | 지표가 0에서 목표값까지 올라감(`CountUp`) |
| 누름 · 올림 | 버튼 누를 때 0.98 축소(`press`), 행에 올리면 화살표가 3px 이동(`row-link`), 카드가 2px 떠오름(`lift`) |
| 완료 | 체크 아이콘이 튀어나옴(`animate-check`) |

## 빠른 이동 (⌘K)

`components/layout/CommandPalette.tsx` — ⌘K(Windows Ctrl+K)나 사이드바의 검색 버튼으로 엽니다. 화면 이동, 자주 하는 작업(새 평가, API 연결, 비교 세트 만들기, 시작 가이드), 테마 전환을 검색하고 ↑↓·Enter 로 실행합니다.

## 처음 쓰는 사람

- 개요 머리글의 **처음 사용하시나요?** → `/guide/start`(도움말 › 시작 가이드).
- 준비가 끝나지 않았으면 개요 맨 위에 **시작하기 카드**: 준비 상태 막대, 다음 단계 버튼, 단계 목록(다음 단계 강조).
- 시작 가이드는 서버의 준비 상태(`/api/overview` 의 `onboarding`)를 읽어 단계마다 완료 표시를 붙이고, 목차는 스크롤 위치를 따라 강조됩니다.
